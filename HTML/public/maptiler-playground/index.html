Why MapTiler

Maps without the platform tax

I've spent years in ArcGIS Enterprise and cloud GIS. MapTiler is what I use when I want modern web maps fast — open styles, sane billing, and an SDK that feels like writing the web.

MapLibre at the core

The SDK sits on MapLibre GL JS, so styles, expressions, and PMTiles workflows transfer. I'm not locked into a closed renderer.

One key, many services

Basemaps, geocoding, elevation, weather, and terrain mesh from the same Cloud account — enough to ship a globe demo or a field game without wiring five vendors.

Built for agents & humans

I maintain MapTiler challenges and grading tooling against maptiler-skills so coding agents learn the platform the way I use it.

Real data, real tiles

Satellite, outdoor, ocean, and custom PMTiles sit beside Natural Earth and survey GeoJSON — the same stack I use for archaeology games and admin-boundary tools.
