# Agent solutions

## Example pack (demo)

Files already in this folder are **example output** for the scoreboard.
On the hub, use **Grade example solutions/** to score them.

## Your own agent run

1. On the scoreboard, click **Copy ALL challenges prompt**.
2. Paste into your agent with the MapTiler skill loaded.
3. Save the agent’s files as `C1.html` + `C1.meta.json` (and so on).
4. On the scoreboard, **Upload your solutions** → **Grade uploaded files**.

Do not overwrite the example pack unless you intend to replace the demo.
