What Vector Ledger is

Vector Scope AI’s collaborative GIS editing product—live on AWS.

Versioned vector layers in an AWS lake, with approvals, then publish for maps and desktop analytics. Staff and partners propose changes; approvers review the changelog; publish yields GeoParquet and PMTiles—not a GeoJSON product line.

Sandbox → upload shapefile → convert → edit proposals → approve → batch apply → new lake version → publish GeoParquet/PMTiles

Ledger Setup: Create a sandbox, upload a shapefile zip, convert to versioned GeoParquet

Ledger Editor: Staff and volunteers draw and edit features in the browser—adds, edits, and deletes stay pending until approved

Ledger Dashboard: Review, approve, or reject proposals plus QC

Ledger Lake: Export GeoParquet and PMTiles/TileJSON for desktop GIS and web maps

Built on AWS

Vector Ledger on AWS — Cognito-authenticated SPA, Lambda/API Gateway control plane, DynamoDB proposals, ECS convert/apply, S3 GeoParquet + PMTiles lake.

  1. Clients: Browser SPA (CloudFront + S3); public playground embed on this site
  2. Auth & edge: Cognito, CloudFront, WAF rate limits on public API paths, SES invites
  3. API / control plane: API Gateway → Lambda; DynamoDB for sandboxes, proposals, jobs, entitlements
  4. Workers: ECS Fargate convert image — shapefile→GeoParquet+PMTiles and proposal apply
  5. Ledger Lake: Private versioned S3 (GeoParquet + PMTiles); sandbox versions + proposal history—not Iceberg tables today
  6. Consumers: PMTiles/TileJSON for web maps; presigned GeoParquet for desktop GIS

Future: Iceberg table management and Athena analytics on the same GeoParquet lake.

Why this exists

The usual mess: shapefiles in email, a geodatabase nobody else can open, or a web map with no file you can take home.

Vector Ledger: collaborative edit → approve → publish. Versioned GeoParquet lake plus PMTiles for web maps.

Data platforms like CARTO and Wherobots are strong at lakehouse analytics. We are aimed at the people who still have to change the lines on the map—with sandboxes, proposals, and a changelog you can trust.
